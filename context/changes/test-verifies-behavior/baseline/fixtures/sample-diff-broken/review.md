## Findings

### `src/e2eTest/java/com/nextslope/e2e/HtmxSmokeE2eTests.java`

- **line 229** · medium · `e2e-conventions` — `page.waitForTimeout(500)` is a fixed sleep added to 'settle' an HTMX swap. The convention requires assertion-based or condition-based waits (e.g. PlaywrightAssertions.assertThat auto-waiting or page.waitForFunction), not fixed timeouts.

### `src/main/java/com/nextslope/profile/PreferenceProfileService.java`

- **line 30** · high · `constructor-injection` — Field `@Autowired private ProfileAuditRepository profileAuditRepository;` introduces field injection and a non-final collaborator on a @Service class. It should instead be a `private final` field supplied via the existing @RequiredArgsConstructor.

### `src/main/resources/application.properties`

- **line 15** · critical · `ddl-auto-validate` — `spring.jpa.hibernate.ddl-auto` was changed from `validate` to `update`, letting Hibernate mutate the schema instead of failing fast on mapping mismatch. This must remain `validate`; the new entity's columns should be introduced purely via the Flyway migration.

### `src/main/resources/db/migration/V3__create_preference_profiles.sql`

- **line 7** · critical · `flyway-forward-only` — This is an edit to an already-applied migration (V3), adding a `display_nickname` column via a context-diff change rather than a new V{n+1} migration file. Corrections to applied migrations must ship as a new forward migration.

### `src/main/resources/db/migration/V6__create_profile_audit.sql`

- **line 7** · medium · `flyway-forward-only` — `id SERIAL PRIMARY KEY` is Postgres-specific DDL and will not run on H2 in PostgreSQL-compatibility mode; use the portable `BIGINT GENERATED BY DEFAULT AS IDENTITY` idiom used elsewhere in the repo.
